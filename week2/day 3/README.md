## Project Overview
This project is my first machine learning model. It uses the Iris dataset to predict the type of flower based on its measurements.

The main goal of this project is to understand the basic machine learning workflow:
Data → Train → Predict → Evaluate

---

## Dataset
The Iris dataset contains flower measurements:
- Sepal length  
- Sepal width  
- Petal length  
- Petal width  

It has three classes:
- Setosa  
- Versicolor  
- Virginica  

---

## Steps in the Project
1. Load the dataset  
2. Explore and understand the data  
3. Split data into training and testing sets  
4. Train a Decision Tree model  
5. Make predictions  
6. Evaluate accuracy
